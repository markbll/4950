# Apache / LiteSpeed (cPanel) notes

`dist/.htaccess` is generated by `npm run build` (`scripts/htaccess.mjs`) from the same
redirect map and CSP hash as the Nginx config. Don't edit it on the server — it is
replaced on every deploy.

If the host needs its own lines (for example cPanel → MultiPHP Manager adds an
`AddHandler application/x-httpd-ea-php83 .php` block), copy them into
`deploy/apache/htaccess.local` (create it) and rebuild — they are placed at the top of
the generated file. Check the live `.htaccess` before your first deploy for such lines.

Staging privacy on cPanel: Files → Directory Privacy → the subdomain folder →
"Password protect this directory". (The generated file already sends
`X-Robots-Tag: noindex`, and robots.txt disallows everything on non-production builds.)
